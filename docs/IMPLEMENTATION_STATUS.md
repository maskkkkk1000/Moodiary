## 本次审计修复

- 编辑器的版本检查进入事务，修改时间在系统时钟回拨后仍单调递增；合法备份日期与仓储统一为公元 0001–9999 年。
- 草稿保存原显示时间，换时区后仅编辑笔记不会改变原 instant；保存期间禁止继续输入和丢弃，避免删除未提交的新草稿。
- 清理同时保护持久草稿照片，删除条目时立即删除无其他引用的自有图片；未完成导入保留24小时缓冲。草稿损坏则停止清理。
- 中断恢复的标记成为全局写入/导出保护，后台备份必须先恢复；回滚失败后不再让新记录被下一次启动覆盖。
- 周目标结束当天仍可完成，不会提前断 streak；指标按日期差计算，不再枚举数千年历史。
- 提醒保留六小时内仍有效的逾期任务，每次触发使用独立通知标识；独立小时修复任务与时间/时区广播防止单次异常永久中断提醒链。
- 本地自动备份按 UTC 日期保留，云端失败重试不重复挤占本地七份历史；先临时写入并校验，再命名为成功备份。
- Drive 列表处理分页；断开执行 Google 撤权并清理缓存令牌。由于没有测试账号，不声称这些远端行为已实测。
- Room/偏好 Flow 失败转为可见错误和重试，避免直接崩溃；不可读偏好只使用显示默认值，不覆盖原文件。
- 大字号底部导航使用保留内容说明的图标布局；月份标题与切月按钮分行，窄屏日历带横向滚动提示并保留至少48 dp日期触摸区域。管理、目标、提醒、日记和编辑页的操作按钮自动换行。PDF 页面显式白底，长中文笔记分页后仍可读。
- Drive 授权结果及平台调用异常转为可见状态，避免授权回调直接抛出至主线程；真实 Google 授权仍待外部配置验收。
- 新增“更多 → Language / 语言”：跟随系统、简体中文、English。采用 AppCompat/Android 应用语言存储，同步 Android 13+ 系统设置；398组中英文资源覆盖页面、日期/星期、统计说明、常见提示及PDF标题。语言切换不改动已存日记和草稿，语言不纳入日记ZIP恢复。

## 性能与实际限制

JVM 最近一次结果（毫秒，短文本、无照片，非 Android 帧率）：

| 条数 | 时间线筛选/排序 | 组合搜索 | 统计 | ZIP 写入 | ZIP 读取校验 |
|---:|---:|---:|---:|---:|---:|
| 10 | 0 | 0 | 0 | 6 | 0 |
| 100 | 2 | 0 | 0 | 3 | 5 |
| 1,000 | 4 | 0 | 4 | 18 | 12 |
| 10,000 | 4 | 10 | 59 | 94 | 88 |
| 50,000 | 19 | 15 | 204 | 416 | 220 |

Android 模拟器最近一次真实 Room 50k：全量替换 **4,097 ms**，读取第一页100条 **3 ms**，全量一致快照 **217 ms**；SQLite 查询计划使用时间戳索引。另一个真实 Compose 用例中，50k时间线（含数据替换）**2,946 ms**、搜索 **419 ms**、月历导航 **187 ms**、统计导航 **429 ms**。这些是该次测试墙钟耗时，受模拟器、缓存和主机负载影响，不是严格 benchmark/帧率。

当前屏幕使用后台一致性快照和 LazyColumn，关系查找建立索引；DAO 支持键集分页，但 UI 尚未改成数据库分页流。50k 短日记通过不等于50k超长笔记或海量照片通过。生产恢复采用磁盘暂存和流式图片校验；数据库 JSON 仍需对象化，限制64 MB，单图32 MB，整个归档/展开内容2 GB，最多20,003成员。设备空间不足会报错并保留原日记，无法保证极低剩余空间下完成备份。

## 数据库与迁移

- Room **schema v1** 是首次基线，导出文件 `app/schemas/app.moodiary.core.database.MoodiaryDatabase/1.json`。
- 没有任何旧生产版本，因此没有虚构 v0→v1 或无意义升级。没有 destructive fallback。
- 已测试同版本关闭重开保留数据，并测试未知更高版本拒绝打开、原内容不被删除。
- 将来发布后变更结构必须增加版本、注册显式 Migration，并针对每个已发布版本加入 MigrationTestHelper 升级测试。这是将来结构升级的要求，不把不存在的历史迁移标成已验证。

## 备份/恢复约定

本地 ZIP 完整携带日记、情绪、活动、分组、目标、完成记录、提醒、模板、重要日期、可移植设置和照片；不携带 PIN、OAuth令牌、设备权限和未保存草稿。备份和 PDF/CSV/JSON 是明文敏感文件。PIN 是界面锁，不是数据库加密。

恢复采用用户确认后的“整体替换”，没有合并恢复。成功后关闭自动备份目的地和生物识别设置，保留本机 PIN。发生进程中断时先恢复旧归档再开放写入。若回滚介质也遭外部损坏，应用保持禁写状态并显示错误，不假装恢复成功。

自动本地备份需要所选文件提供器支持创建、读回、重命名和删除；撤销授权、空间不足或不支持时会记录错误，不删除原数据库。Drive 日文件以 ID 更新，保留七份。文档化的 Google [授权方式](https://developer.android.com/identity/authorization)、[私有 appDataFolder](https://developers.google.com/workspace/drive/api/guides/appdata) 和 [OAuth 撤权](https://developers.google.com/identity/protocols/oauth2/native-app#tokenrevoke) 是实现参考；这里的链接不代表已获得用户账号授权。

## 部分完成、外部阻碍与风险

1. **Drive 真实集成验证受阻**：缺少用户 Google Cloud 项目、Drive API 启用状态、Android OAuth 客户端（包名/签名 SHA-1）和同意授权的测试账号。代码可编译、错误不影响本地记录；真实上传/下载/分页/撤权/自动重试需配置后验收。
2. **生物识别硬件验收未完成**：已接平台强生物识别 API、能力检查与 PIN 回退，但没有已录入生物识别的目标真机，不能证明传感器成功/移除行为。
3. **提醒/自动备份平台边界**：采用 WorkManager 近似调度，不承诺精确到分钟。多厂商 Doze、重启、自启动限制需目标手机长时间测试。
4. **可访问性仍需人工验收**：基础语义、字号及深色支持已做；未完成真实 TalkBack 用户的全流程人工检查，不宣称无障碍认证。
5. **中英界面已支持**：支持跟随系统和手动选择，切换不翻译或重写已保存的日记、可编辑名称（含已有默认名称）及提醒消息。JSON/CSV机器字段保持稳定；底层完整性诊断、系统或服务返回的详细错误仍可能含英文。API35已实测，旧版系统通过AppCompat兼容支持，尚未逐个Android版本进行真机验证。
6. **发行设置**：debug APK 可安装；release APK 未签名，用户需自己的发行密钥。当前 compile/target 35，不将其称为已满足未来商店上架政策。
7. 可选 P2 自定义强调色/字体、严格统计置信区间/回归、外部健康数据、合并恢复均未纳入已完成声明；主计划将其列为可选/未来方向。

## 用户仍需设置及建议下一步

- 本地功能无需账户：安装 debug APK 即可试用；按需授予照片选择、通知及备份目录访问。
- 按 README 配置自己的 Google Cloud/OAuth/测试用户，并验收一次真实云端往返；无需提供服务器账号系统或嵌入客户端密钥。
- 在目标手机验证强生物识别、后台提醒、重启、文件提供器、TalkBack 和长时间使用。
- 发布前使用自己的密钥签名并备份签名材料；保留 schema v1。后续任何数据结构升级必须有显式迁移及真实升级测试。
