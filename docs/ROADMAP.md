# Moodiary 路线图

当前源码：**0.2.0 / versionCode 2 / Room schema 2 / backup format 2**。稳定起点为 0.1.0；这不是 1.0。基线范围见 [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md)，本轮验收与限制见 [ITERATION_1](ITERATION_1.md)。

## 已完成（纳入 0.1.0 基线）

- 本地日记、多条/天、照片私有副本、时间线、日历、搜索筛选。
- 情绪/活动/分组管理、模板、主题、重要日与成就。
- 统计、当日/次日观察性关联、样本置信提示、目标联动与连续记录。
- PIN 哈希与平台生物识别接入、提醒和后台任务、本地备份/验证恢复、自动备份、JSON/CSV/PDF 导出。
- 中文/英文/跟随系统切换；语言重建与草稿保留测试。
- Room 初始 schema、JVM/Room/Compose 回归测试及 50,000 条合成日记性能检查。
- Git 忽略与行尾规则、Conventional Commits、分支约定、版本文档和发布检查单。
- 公开仓库发布前对开发历史邮箱进行匿名化；原始历史保留为私有存档。
- 2026-09-29 用户反馈除 Google Drive OAuth 配置外真机功能正常；发行签名与 Debug 迁移说明已准备。跨厂商长期验收仍继续进行。

“已完成”表示本地实现及已有验证范围，Google Drive 真正云端往返、真实设备生物识别和厂商后台行为不在已验收范围。

## 已完成（第一轮迭代 0.2.0）

- 柔和主题、较大的心情选择、活动图标、卡片间距与选择反馈，中文/英文同步覆盖。
- Emoji 预设、自定义输入与预览；心情、活动和小目标图标持久化，活动支持 Material 图标和颜色自定义。
- 统一统计日期/心情/活动/模块筛选，活动 OR、多目标筛选，DataStore 持久化和重置，后台按需计算与折叠卡片。
- 正常启动进入编辑器，优先恢复合法草稿；通知指定入口、历史编辑和恢复锁保留。
- 独立小目标 CRUD、排序、归档/恢复、安全删除；每日 1/0/未记录、历史补录、唯一日期约束及周/月完成率。
- 显式 Room 1 → 2、历史 schema 保留；备份格式 2 兼容格式 1；完整 ZIP/JSON/PDF 接入。
- 新增业务、Room、备份、筛选持久化、导航与 Compose 回归；10/100/1000 个目标各一年结果的统计压力测试。

## 正在进行

- 0.2.0 最终发布准备、签名升级与真机扩大验收；结果以本轮验收记录为准。
- 0.2.x：反馈修复、实际设备适配、后台/提醒/生物识别和无障碍持续验收。保留 0.1.x 安全修复能力，不破坏用户数据。
- 按阶段提交并持续验证；GitHub 仓库：`maskkkkk1000/Moodiary`。

## 下一功能版本：0.3.0

- 用户提供 Google Cloud OAuth 配置，在有 Play 服务的设备上验收 Drive 上传/列表/恢复。
- 完善撤销授权、断网、限额、重试与自动云备份的真实服务测试。
- 视验收结果补充小目标每日提醒和独立 CSV；继续完善文案与使用反馈。

## 长期计划

| 版本 | 目标与验收 |
| --- | --- |
| 0.3.0 | 用户 Google Cloud OAuth 配置、真实 Drive 上传/下载/恢复、撤销授权/断网/重试/异常验收 |
| 0.4.0 | 统计与 Insights 增强、流式/分页性能优化、更完整测试；继续禁止因果断言 |
| 0.9.0 | Release Candidate；真实设备长期使用、迁移升级测试、发布前全面审计 |
| 1.0.0 | 仅在正式发布条件达成后创建；签名、数据安全、迁移、备份恢复、设备验收和 release checklist 全部审核 |

版本不按日期强行发布。外部凭据、设备及已知风险未消除时，记录阻塞，不能把文件或接口的存在当作功能验收。
