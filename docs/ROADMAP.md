# Moodiary 路线图

当前：**0.1.0 基线 / Room schema 1**。这是开发基线，不是 1.0 正式发布。详细行为验收与限制见 [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md)。

## 已完成（纳入 0.1.0 基线）

- 本地日记、多条/天、照片私有副本、时间线、日历、搜索筛选。
- 情绪/活动/分组管理、模板、主题、重要日与成就。
- 统计、当日/次日观察性关联、样本置信提示、目标联动与连续记录。
- PIN 哈希与平台生物识别接入、提醒和后台任务、本地备份/验证恢复、自动备份、JSON/CSV/PDF 导出。
- 中文/英文/跟随系统切换；语言重建与草稿保留测试。
- Room 初始 schema、JVM/Room/Compose 回归测试及 50,000 条合成日记性能检查。
- Git 忽略与行尾规则、Conventional Commits、分支约定、版本文档和发布检查单。
- 2026-09-29 用户反馈除 Google Drive OAuth 配置外真机功能正常；发行签名与 Debug 迁移说明已准备。跨厂商长期验收仍继续进行。

“已完成”表示本地实现及已有验证范围，Google Drive 真正云端往返、真实设备生物识别和厂商后台行为不在已验收范围。

## 正在进行

- 0.1.x：Bug 修复、真实设备适配、基线稳定性维护；不进行破坏性架构重写。
- 按提交阶段持续执行验证，并维护版本文档。GitHub 仓库：`maskkkkk1000/Moodiary`。

## 下一功能版本：0.2.0

- 在已实现中英文切换基础上完善国际化、文案、技术错误翻译与布局。
- 真机提醒、后台任务、生物识别及无障碍验收和优化。
- UX、稳定性改进及对应回归测试。

## 长期计划

| 版本 | 目标与验收 |
| --- | --- |
| 0.3.0 | 用户 Google Cloud OAuth 配置、真实 Drive 上传/下载/恢复、撤销授权/断网/重试/异常验收 |
| 0.4.0 | 统计与 Insights 增强、流式/分页性能优化、更完整测试；继续禁止因果断言 |
| 0.9.0 | Release Candidate；真实设备长期使用、迁移升级测试、发布前全面审计 |
| 1.0.0 | 仅在正式发布条件达成后创建；签名、数据安全、迁移、备份恢复、设备验收和 release checklist 全部审核 |

版本不按日期强行发布。外部凭据、设备及已知风险未消除时，记录阻塞，不能把文件或接口的存在当作功能验收。
