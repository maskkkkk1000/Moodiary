# 第一轮迭代验收记录

需求：[moodiary_plan2.md](../moodiary_plan2.md)。开发分支 `feature/iteration-1`，稳定起点 `v0.1.0`。0.2.0 源码已合并到 `main`，签名 APK 已发布到 [GitHub Releases](https://github.com/maskkkkk1000/Moodiary/releases/tag/v0.2.0)；发布验证见下文。

## 实现范围

- 柔和主题、卡片间距、较大的心情图标及短选择动画；编辑页活动流式排列，时间线保留照片预览。
- 心情、活动及小目标图标持久化；Emoji 预设、自定义输入和预览，活动和小目标可用内置 Material 图标。历史心情快照不改写。
- 正常启动优先恢复合法草稿，否则新建记录；保留恢复锁。通知进入记录或目标页面；目标提醒定位指定目标。重建和语言切换保留当前页面。
- 统计支持本周、本月、7 天、30 天、3 个月、1 年、全部、自定义日期；心情和活动多选，活动使用 OR。模块可选、可折叠，未选模块不计算。
- 筛选通过独立 DataStore 保存，支持重置；后台计算和错误/加载/空状态。
- 独立小目标管理：创建、编辑、图标、排序、归档、恢复；仅无结果的目标允许确认后删除。
- 每日成功、未做到和未记录三态；同一天更新同一条记录，点击已选结果恢复未记录；历史补录支持，新增未来日期拒绝。
- 小目标汇总、按目标筛选、周/月趋势；JSON 和完整备份含目标与结果，PDF 增加小目标摘要。

## 数据与统计约定

Room 2 通过显式 `MIGRATION_1_2` 只新增 `binary_goals` 和 `binary_goal_records`；13 张原表定义保持一致。记录具有 `(goalId,date)` 唯一索引，外键阻止删除有历史的目标。schema 1/2 JSON 均保留。

备份格式为 2；读取格式 1/2，旧备份缺失小目标时恢复为空，未知未来版本拒绝。恢复继续使用完整校验、事务、临时照片及持久化回滚保护。旧版应用不能读取格式 2 备份或 schema 2 数据库，不支持直接降级。

完成率为 `success / (success + failed)`，没有记录时显示未知。未记录天数从创建日或最早显式补录日开始；归档只隐藏，不抹去历史。当前设备时区用于时间戳的日归属，小目标记录本身存储 ISO 本地日期。

日记统计基于日期、心情和活动共同筛选后的 Entry 重新计算。次日分析仅比较筛选后相邻的两个有记录日期。习惯目标和小目标有独立结果，因此仅遵循日期与目标筛选，不依赖当天是否有日记；界面明确说明。

周趋势最多展示最近 104 周、月趋势最多 36 个月，汇总使用整个筛选范围。统计筛选是本机显示偏好，不进入日记备份。大量目标分批展示明细，计算复杂度按记录数增长。
